## Si eres alumno o alumna

1. Abre **tu propia copia** del laboratorio, en la rama donde terminaste el ejercicio 8 con Actions verde.
2. Crea allí una rama `ejercicio-9-promocion`. No crees otro repositorio ni edites esta rama docente.
3. Sigue la [guía paso a paso del ejercicio 9](EJERCICIO_9.md) o el Word/PDF de clase. Trabajarás en dos archivos nuevos y el workflow existente.
4. Comprueba tres ejecuciones en **tu propia copia**: verde inicial, roja por nombre de integración no aprobado y verde corregida.

Este ejercicio es una **ampliación opcional**: el temario de 25 horas termina en el taller del ejercicio 8.
